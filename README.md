# UGV_client

UGV(무인지상차량)의 시설 감시와 원격 제어 화면을 구성한 웹 대시보드 프런트엔드 목업입니다.
Express가 HTML, CSS, JavaScript와 이미지 파일을 제공합니다.

## 화면과 구현 기능
- `index.html`은 시설 감시 화면이며 정적 이미지 지도 위에 UGV 두 대를 표시합니다.
- `public/script.js`는 하드코딩한 초기 좌표에서 UGV 아이콘을 가로 또는 세로로 왕복 이동시킵니다.
- 도로 균열, 화재 발생, 미확인 거수자 중 하나를 임의로 골라 지도 표시와 로그를 생성합니다.
- 지도 표시를 누르면 유형, UGV 식별 정보, 시간, 예시 사진을 팝업으로 표시합니다.
- 로그의 View Photo 버튼으로 사진을 확인하고 Clear Log 버튼으로 표와 지도 표시를 지웁니다.
- `cam_index.html`은 원격 제어라는 메뉴 이름의 카메라 표시 화면입니다.
- `cam/script.js`는 브라우저의 `getUserMedia`로 사용자 기기 카메라 영상을 요청해 재생합니다.

## 목업 범위와 한계
지도는 `public/Airbase_map.png` 파일이며, 위치와 이벤트는 클라이언트에서 생성하는 모의 데이터입니다.
실제 UGV 위치 수신, 결함 감지, 차량 제어 명령 전송을 구현한 코드는 해당 화면 스크립트에 없습니다.
카메라 화면은 원격 UGV 스트림이 아니라 접속한 기기의 카메라를 사용합니다.
감시 로그와 UGV 관리 메뉴는 별도 화면이 아닌 `index.html`로 연결됩니다.
로그는 DOM과 JavaScript 배열에서 처리되며 서버에 저장하는 코드는 없습니다.

## 기술 구성
- Node.js와 Express 4.x를 사용합니다.
- 화면은 별도 프런트엔드 프레임워크 없이 HTML, CSS, JavaScript로 구성되어 있습니다.

## 로컬 실행
1. Node.js와 npm이 설치된 환경에서 저장소 루트로 이동합니다.
2. `npm install`로 의존성을 설치합니다.
3. `node app.js`로 서버를 실행합니다.
4. `http://localhost:3000`에서 시설 감시 화면을 확인합니다.
5. 원격 제어 메뉴에서 카메라 사용 권한을 허용하면 기기 영상을 표시합니다.

카메라 기능은 브라우저의 미디어 장치 API 지원과 카메라 권한이 필요합니다.
포트는 `app.js`에 3000으로 지정되어 있습니다. `npm test`에는 실제 테스트가 등록되어 있지 않습니다.

## 파일 구조
- `app.js`: Express 정적 파일 제공과 서버 실행 코드입니다.
- `index.html`, `public/`: 시설 감시 화면, 동작 스크립트, 스타일, 지도와 예시 이미지입니다.
- `cam_index.html`, `cam/`: 카메라 화면, 카메라 초기화 스크립트와 스타일입니다.
- `route.js`: 라우터 코드가 있으며 현재 `app.js`에는 라우터를 연결하는 `app.use` 호출이 없습니다.
- `package.json`, `package-lock.json`: 의존성 선언과 잠금 파일입니다.
